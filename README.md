# Libraries.dev

**High-crafted UI libraries for AI agents, rewritten as a unified React application.**

Seven production-grade React libraries for the micro-interactions that make an interface feel alive:
- **Border beam** (`border-beam`) — A soft glow that rides the border of a card, button or input
- **Thinking orbs** (`thinking-orbs`) — Orbs that think while models work — 9 mathematical geometry states
- **Bot avatars** (`bot-avatars`) — Animated bot avatars with living faces — 18 glossy shapes, 4 states, gaze tracking
- **Liquid gooey** (`liquid-gooey`) — Pieces that merge like goo and morph like jelly with real SVG filters
- **Voice glow** (`voice-glow`) — A glow that radiates with voice volume from the bottom of chat inputs or screens
- **Liquid metal** (`metal-fx`) — Real-time WebGL metal shader effects with reflections and catch-light
- **Image FX** (`img-fx`) — WebGL pixel mosaic image loader that settles and dissolves into photography

## Running the Application

```bash
npm run dev
```

Starts the Vite development server on port 3000 at `0.0.0.0`.

## Building for Production

```bash
npm run build
```

Creates the optimized production bundle in `dist/`.

## Architecture & Features

- **Interactive Showcases**: Dedicated interactive laboratories for every single library with live parametric tuning (presets, palettes, physics, speed, shapes, and audio inputs).
- **Master Overview**: Side-by-side gallery of all 7 libraries executing in real-time with live WebGL shaders and canvas graphics.
- **Agent Prompts**: One-click copyable prompts pre-configured for Claude Code, Cursor, and Codex.
- **Dark & Light Mode**: Seamless theme detection and synchronized styling across all canvases and shaders.
